# Description

Source code for the Finda Model Agency platform - website only

Finda was a self-serve platform allowing models to present themselves, and booking agents to find and book individual models for modelling jobs.

## Features

### Model view
Allow models to create individual profiles with portfolio images

### Agent View
Allow agents to create modellling jobs and book models directly

### Mother Agent View
Allow Mother Agencies to manage multiple Agents

### Escrow Payments
Collect and hold payments for jobs in an Escrow-like account, prociding safety for both Models and Agents in the bookng process: Models who completed the assignment woudl be automatically paid as funds were available. Any bookings that were not completed would be automatically refunded.

### Mobile Support
An Android and an iOS app for Models was also available to manage portfolios and bookings.
